Legado manga shape layout and local vision
========================================

The shape-aware text layout, fixed-area glyph sizing, bounded bubble interior
estimation, background statistics, seed ordering, square dilation, and related
geometry/inference contracts, optional bitmap preprocessing order, and Otsu
threshold strategy are adapted from:
https://github.com/ciddwd/overlay-translator
Reference commit: 64a7aa2c9605c88dd35bdeea42ab5c0f1c18ce5e
Copyright the overlay-translator contributors.
Licensed under Apache License 2.0; see LICENSE-Apache-2.0.txt.
Legado modifications include package changes, bounded persistent masks, reader
ROI transformations, idle session release, bounded OCR working copies,
cancellation-safe bitmap ownership, source-calibrated typography instead of automatic
fixed-area enlargement, source-center anchoring, and integration with existing caches.

Optional PP-OCRv5 mobile pipeline
The DB postprocessor, bicubic perspective sampler, and normalization/CTC contracts are adapted from the same
overlay-translator reference under Apache-2.0. Model weights are NOT bundled.
They are downloaded only on request from PaddlePaddle's official repositories:
https://huggingface.co/PaddlePaddle/PP-OCRv5_mobile_det_onnx
https://huggingface.co/PaddlePaddle/PP-OCRv5_mobile_rec_onnx
License: Apache-2.0 (declared by both model repositories).
Exact revisions, sizes and SHA-256 values are pinned in MangaPaddleModelCatalog.

Optional PP-OCRv6 model sets (weights NOT bundled)
Official Small detector, Small/Medium recognizers and matching dictionaries:
https://huggingface.co/PaddlePaddle/PP-OCRv6_small_det_onnx
https://huggingface.co/PaddlePaddle/PP-OCRv6_small_rec_onnx
https://huggingface.co/PaddlePaddle/PP-OCRv6_medium_rec_onnx
Japanese manga recognizer fine-tune by fumetodev:
https://huggingface.co/fumetodev/PP-OCRv6_small_rec_manga_ONNX
All declare Apache-2.0. Each set uses pinned revisions, byte sizes and SHA-256.
Official YAML preprocessing is BGR; the manga fine-tune declares RGB input.
