# 阅读器正文与呈现契约

## 唯一正文与旧行为

`ContentProcessor → ReaderChapterSourceParser → ReaderChapterSource` 是正文处理及坐标生成入口。
`ReaderChapterSource.semanticContent` 与 `paragraphs` 是业务消费者的共同依据；搜索、书签、高亮、
朗读、角色、BGM 和 Web 不得自行剥标签、重数段落或从绘制结果推算正文。
不同请求可独立构建结果，不要求共享缓存或全局实例，但必须使用相同处理实现与设置。

- 本地 EPUB/MOBI 采用旧文字提取规则，输出普通正文和既有图片标签，不生成新的 `<usehtml>` 业务通道。
- EPUB 实体在本地提取边界解码一次；普通文字不再二次反转义。MOBI 沿用旧版实体处理约定。
- 净化、regex/JS、简繁、重新分段、标题去重及编辑沿用普通正文处理顺序，只执行一次。
  样式不能限制规则跨原 HTML 节点匹配或使原来可编辑的普通正文变成“不支持”。
- 资源路径、图片、正文与持久化字段不因可选呈现而改写。用户编辑后的章节内容始终优先于原文件。
- 旧网文显式 `<usehtml>` 是既有输入协议，继续使用平台 HTML 适配器的旧文字投影和角色分配资格。
  关闭特殊样式时恢复普通净化和重新分段；开启时保留显式 HTML 的规则保护边界。
  禁止无生产调用方的正则 HTML fallback 静默给出另一种文字定义。

## 文字与段落坐标

1. 正文偏移采用 Kotlin String 的 UTF-16 code unit，范围 `[start, endExclusive)`；边界不得切开代理对。
2. `characterCount == semanticContent.length`。图片继续占一个 U+FFFC；标题不占正文坐标。
3. 普通正文中的既有缩进和已注入角色标签继续占字符位置，不借本次改动改变历史数据含义。
4. `paragraphs` 标识处理后旧非空输入段的编号及其正文范围；标题不计数。既有显式控制标记沿用旧解释。
5. 本地同一正文和内容处理配置下，开启或关闭特殊样式，不得改变文字、段落编号、搜索或朗读位置。
6. BGM 的 AI/手动分配、总览、胶囊与播放共用这些段落；不按 HTML 块、视觉行或重新 split 正文计数。
   读取、布局和样式切换不得重写 BgmSceneMark 的编号、池、曲目、音量、状态或时间。

正文经过净化、编辑或重新分段发生实质变化时，沿用旧功能行为；本契约不承诺自动恢复任意改写前的旧段序。

## 可选本地呈现

原始 HTML 的样式、列表、引用、标题、分隔线、链接和锚点以正文范围表达。
本地适配器使用 Jsoup 源位置跟踪读取属性；同一份旧格式化流程在实际复制、替换、删除和实体解码时
维护 UTF-16 来源范围。呈现解析器不再生成另一份业务文字，也不通过全章文字比较判断所有样式是否有效。
DOM 与字符来源数组只用于构建过程，交付给阅读器的结果仅保留文字及范围元数据。

- `LocalBook.getPresentation` 返回与原始规范传输文字绑定的范围数据。正文缓存只保存新管线的普通正文；
  不迁移或解释本分支中途版本生成的本地富文本缓存，测试前由用户清理并从原文件重建。
  已有用户内容优先，不用原文件覆盖用户编辑后的正文，也不新增自动清缓存逻辑。
- 标题去重、空白整理、简繁、重新分段、净化、编辑及角色标记注入沿用原文字算法，在实际变换时移动范围。
  regex/JS 只执行一次；不对 HTML 属性套用正文规则，也不以最终字符串是否完全相同作为呈现开关。
- 替换范围处于同一样式、链接及段落上下文内时继承可确定属性。跨不同范围的替换只降级不确定区域；
  边界插入没有唯一归属时使用普通样式。删除目标会使其锚点失效，去重标题的章首锚点保留在正文起点。
- 角色标签插入保留原胶囊识别，既不拆开标签，也不清空其他文字的样式、链接和锚点。
- 同一规范正文段可对应多个视觉块。空行、列表编号、引用线、分隔线和 BGM 胶囊不增加正文字符或存储段号；
  同一列表项跨多个视觉段时仅绘制一次标记。
- CSS 按文档顺序应用于呈现，保留 `main` 的既有行内隐藏过滤与 H/ruby 设置，不新增 CSS 隐藏造成的正文删减。
  当前消费对齐、字重、斜体和文字装饰，不宣称支持尚未实现的 margin/border/font-size CSS 布局。
- 普通正文的左对齐／两端对齐统一跟随阅读配置，书籍中对应的 CSS 不覆盖阅读设置。
  显式居中／右对齐及结构块的对齐继续保留；本地呈现与旧 HTML 在共享测量入口使用同一优先级。
- 测量版本由 `PageEstimateConfig` 统一维护；富文本测量变更通过版本使旧页数和校准桶失效。
  特殊样式开关参与布局身份，开关间不复用持久化精确页数或校准数据，不清理章节正文。
- 复用现有测量和分页原语。结构块可以在绘制时省略注入的正文缩进，但不能删除相应的规范字符和坐标。
- 原文件读取、来源绑定或解析失败只影响对应呈现，不能替换权威正文；记录阶段、章节和原因，不记录正文。
  常规文字处理发生改变不是整章降级的理由，也不允许通过最近文字搜索猜测原样式或锚点位置。

## 内容消费与定位

- 高亮、搜索和跳转在规范正文上定位；无有效匹配或 UTF-16 边界非法时不绘制错误选区。
- 书签/笔记校验来源、章节、目标文字及已保存的上下文；不匹配时使用已有重定位或确认流程，不自动覆盖旧位置。
- 无文本锚点时只能修正越界和代理对边界，不能据此声称找回原句。
- 页书签等持久化页文本按页的正文范围截取规范文字，不保存标题或装饰产生的绘制文本。
  页上下文须对应产生该页的章节输入，正文更新后不混用旧页与新正文。
- 朗读可以省略尾部分隔符，但必须保留绝对正文坐标。
- EPUB 在完整 DOM 上切分章节后再过滤隐藏内容，隐藏标题和空锚点仍可作为章节边界。
- 本地可靠的空锚点作为位置元数据，不插入字符。fragment 百分号解码保留字面量 `+`。
  同一资源有多个目录切片时，非目录 fragment 必须确认唯一归属；缺失或歧义不猜测章首。
- 本地链接使用书内导航；网文相对链接基于当前章节 URL 解析并确认外部打开。脚本、data 和未知协议不自动导航。
- 网文 HTML 的文本编辑在能够生效时降级为普通文字和图片通道，不修改原属性或尝试通用 DOM 回写；
  无效或未命中的记录保留原文。历史普通正文编辑行为保持不变。

## Web 与导出

`getBookContent` 默认保留旧字符串响应；内置 Web 使用 `format=semantic`，获得
`{title, characterCount, paragraphs: [{html, start, endExclusive}]}`。正文位置来自同一 Source，
不计标题、不按 HTML 源码长度计算。Web 不承诺与原生端全部装饰一致。
Web 从 DOM 属性解码图片地址，代理参数独立编码，保留查询参数和资源选项 JSON。
TXT 导出使用可读正文和既有图片通道；图片资源及独立图片导出继续有效。

搜索固定开始时可用的章节集合。后台新增未参与搜索的缓存不打断查询；已搜索章节、规则或处理设置
变化时清除过期会话并提示重新搜索。规则初始化不构成语义变更，结果缓存按书籍及处理配置失效。

## 验证与边界

共享样例位于 `app/src/test/resources/reader/semantic/`。旧文字、段落及 BGM 预期从 main 行为冻结，
不能由被测解析器自行生成。纯函数、处理集成、跨消费者和文件适配器各自验证其职责，复用输入而不重复断言。
样式测试同时校验正文与段序不变，以及样式、装饰和链接到达分页元素。处理集成测试应启用真实呈现入口，
仅替换文件读取依赖，不在处理结束后手工附加呈现来绕过生产条件。角色标签和文字改写后的断言必须检查
未受影响的属性仍然存在，不能把整章呈现丢弃当作正常成功。既有旧网文 HTML 单独固定原协议。

本轮不修改数据库格式，不兼容本分支新富文本编号下创建的 BGM 记录，不新增磁盘缓存迁移或全书清缓存策略。
单元测试和构建不替代 Android PFD、真实 KF6/KF8、真机和旧数据升级实测。
