# 漫画翻译设置与图片菜单

2026-10-29。界面 owner 位于 `feature/manga/translation`；漫画阅读器 host 通过回调连接图片菜单，
翻译引擎和 OCR / 擦字实现保持数据层归属。
自动翻译总开关也可从[漫画全局设置](manga-settings.md)访问，两个入口共享同一配置源。

## 设置面板

使用与“阅读界面”相同的正式 SettingItem 系列，翻译设置、识别与定位、擦字与排版及高级设置
各自使用并列的 `SplicedColumnGroup`。总开关卡片不包裹这些子组，说明文字位于卡片外；
卡片内的模型下载状态使用 `SettingItemWithDivider`，沿用主题的分隔、边框和圆角。
漫画设置页内的翻译分组、阅读器翻译面板及 OCR 高级设置均不用 Tiny 系列。原文语言和目标语言使用下拉；
端侧引擎限定支持的源语言，切换到不支持当前源语言的端侧引擎时，原子切换到该引擎支持的首个语言。
AI / 云端源语言可自动识别，目标提供简体／繁体中文与常见语言。文字和图片模型只显示相应能力项。

说明只保留费用／上传提醒、支持语言、模型大小与性能取舍及必要的生效条件；不展示协议、蒙版或
模型实现说明。模型列表显示供应商与型号。
术语表、高级参数及云端连接设置默认收起。模型下载状态和取消仍可见；清除本书译图需确认，
保留设置和术语表。OCR 参数采用正式 SliderSettingItem，概率／得分以百分之一为一个整数刻度，
外扩使用二十分之一刻度；松手或收起时提交，数值输入和恢复默认沿用正式设置交互。

## 全局翻译配置与按书覆盖

“设置 → 漫画设置”的“漫画翻译”分组直接管理语言、模型、思考强度、定位、OCR／预处理、擦字合成、
字号、图像编辑路径和诊断选项，不再另开页面。宿主为分组绑定 `BindGlobal`，不构造空 bookUrl 的书籍记录，
也不提供翻译、清除译图、术语表等书籍动作。模型下载与云端 OCR 凭据可在此管理。
阅读器中的“漫画翻译设置”入口打开漫画设置并定位到该分组。

`MangaTranslationGlobalSettings.defaults` 存储配置模板；其中 automatic 始终归零，默认自动翻译开关在外层。
BookState 的 useGlobal 默认 true，实际翻译／排版和 settings Flow 都读取同一 effective 配置：
继承模板参数；automatic 使用单本覆盖值，未覆盖时跟随全局默认。本书术语和已发布译图保持独立。
首次关闭继承时从当前全局配置建立本书快照，之后在全局与本书配置之间切换会保留本书快照；
改变本书 automatic 不会覆盖这个快照。书籍参数的显式修改也会建立本书覆盖。
继承中的漫画随全局参数变化，单独设置的漫画不受影响；已发布译图仍保留，重译／重排成功后替换。

## 自动翻译

删除“自动翻译当前页”和“显示译图”。已保存译图始终自动显示。
全局设置提供“默认自动翻译”，阅读器面板只显示“自动翻译本漫画”。
单本未选择时跟随全局默认，手动开关后保存独立覆盖；全局关闭时也能为单本启用。
全局设置独立存于 `manga-translation/settings.json`，单本覆盖存于 `book.json`。
顶部思考模式默认关闭；继承全局设置时也可修改，修改后保存为本书配置。
人名与术语表使用独立 sheet，列表展示原文和译名，支持添加、编辑、删除与保存。

普通图片加载成功和整章数据预加载成功都会记录原图已就绪；预加载仅更新 `sourceReady`，
不伪造显示层的 `Ready`。回调仍校验书籍、页面与重试代次，重试时重置就绪标记。
host 将所有已就绪图片送入翻译 ViewModel，包含当前视口外和相邻章节图片。
队列按页面源身份去重，一次处理一张，已有译图直接恢复；滑动／换章不取消已排队任务。
已入队图片离开当前阅读窗口后仍继续处理，离开阅读器或进入后台则停止，回到阅读器后继续。
每页自动失败不循环重试，也不阻塞后续页；显式重新翻译仍可重试。

关闭本漫画自动翻译停止自动任务，手动单页／整章请求保持独立。取消或清除译图会暂停当前会话的自动队列，
防止下一次重组立即重新请求；重新关闭再开启本漫画自动开关可恢复。自动开关不参与译图／排版缓存身份。
关闭本漫画自动翻译会立即阻断新请求，不等待异步设置写入；所有原图身份均参与重试失效判断，尚未重新加载的
相邻章节图片不能继续使用旧的入队代次。缓存读取失败不触发付费回退，也不阻塞其他图片。

## 单页与整章

设置面板只放本章翻译与本章重新排版。图片长按菜单合并翻译入口：无译图时显示“翻译当前页”，
已有译图时显示“重新翻译当前页”并强制重新翻译，按已保存译图判断。
重新排版当前图片保持独立，并保留保存／分享／复制／设为封面等阅读器操作。菜单可滚动，适应横屏可用高度。
任务执行中禁用新的单页动作；只有已保存可重排计划且选择本地合成时，才启用单页重新排版。

长按动作按 sheet 保存的 pageKey 寻址，host 从 reader pages 构造原图 MangaTranslationPage，
通过 Translate.page／Recompose.page 显式传入。不能改用当前 viewport 的 currentKey，也不改变
当前阅读位置；这覆盖双页及相邻章节图片。ViewModel 拒绝不同 bookUrl 的显式目标，整章动作仍使用
当前章节绑定的 pages。完成后通过已有状态条显示进度／错误，不强制打开设置面板。

## AI 请求重试

漫画翻译基本设置提供重试次数下拉框：默认 3，范围 0..10，0 关闭。沿用全局模板与单本覆盖。
次数不含首次请求；识图／排版返回纠正与临时网络失败共享同一请求预算，默认最多发送四次。
只对失败的 AI 文字请求重试，整图图像编辑模式不显示该设置，不自动重提云 OCR jobs 或图像编辑任务。
设置不改变现有译图身份；取消、认证／配置错误会停止，局部排版和擦字失败不循环重跑。


## 阅读器翻译进度页脚

翻译中入口使用无卡片背景的 AppText 小字，显示本次任务的已完成页数 / 总页数，
不使用页内分段或气泡数量。点击打开既有翻译面板，可查看详细阶段和取消任务。
失败时保留简短失败入口及本次页数；正常结束后隐藏。沿用 ViewModel 的 done / total，
不改变翻译队列、缓存、取消或重试行为。

翻译入口与阅读页脚共用底部安全区，入口跟随页脚左、中、右对齐并放在其上方；
隐藏阅读页脚或尚无阅读页脚时，翻译进度默认放在左下角。阅读菜单展开时隐藏进度入口，避免遮挡菜单。
文字沿用 labelSmall 令牌及阅读页脚白字阴影，点击区域至少 48dp。
