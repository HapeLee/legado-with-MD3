# 漫画翻译

阅读设置“全局”页的第一项“漫画翻译”现在是二级设置入口，翻译默认关闭。
二级页提供翻译总开关、独立的气泡显示开关、自动翻译、原译显示、模型管理、翻译方式选择和缓存清理。
普通设置经 MangaSettingsGateway 原子保存；自动翻译与原译显示和阅读气泡共用阅读器状态。
开启翻译且允许显示气泡后出现默认在左侧居中的“译”气泡；可拖动吸附左右边缘，吸附边和相对高度持久化。
主泡视觉直径 44dp，操作泡 48dp，展开触控框 48dp；收缩时主泡约 50% 藏在边缘外，保留半圆形入口，透明度约 40%。
主泡与自动翻译采用第一版冰蓝玻璃图标的 512×512 透明 PNG，分别显示双语言卡片箭头与图片加 A；墨水屏使用同造型单色绘制。
自动翻译下方显示当前章节已完成页数/任务总页数（含跳过页，无任务为 0/0，暂停保留进度）；显示模式下方随状态显示“原图”或“译文”。
操作泡开启态使用主题色背景染色，保留普通细玻璃边线，不增加深色描边；按压增加 16% 状态遮罩并在 120ms 内缩至 94%。清除保留即时确认框，墨水屏关闭缩放与过渡动画。
点击半圆入口展开“自动翻译”“译文/原图”“清除”；主泡、空白和返回键收起。
长按主泡直接打开漫画翻译设置；半隐藏和展开态均可使用，并提供无障碍长按动作。
拖动超过阈值后不会触发长按，长按成功不会附带触发短按。
5 秒无气泡操作后通过阻尼弹簧动画滑回边缘，操作会重置计时，翻译进度不会重置；按住、拖动、焦点及触摸探索时暂缓。
阅读菜单、设置及弹窗显示时隐藏气泡，恢复时默认半隐藏态。
阅读气泡组以主泡为中心向内展开约 110° 扇形；小窗口保留紧凑排列。
外层为包裹四个气泡的单一圆润凸扇形：固定 32 个方向的支撑线经角向平滑生成凸包络，沿周长等距重采样为 64 个控制点，再以周期闭合三次 B 样条绘制，连接处与闭合处保持二阶连续，展开过程中控制点数量固定。
保留背景模糊，使用低对比度 0.5dp 渐变细边及按高斯衰减叠加的密集柔光描边；绘制位移保留小数像素，子泡与外膜同步使用较轻的弹簧回弹。
漫画翻译设置提供“气泡透明度”滑条（0%～100%），不显示小字说明；采用绝对透明度：0% 完全不透明，50% 半透明，100% 完全透明。默认值为 0%。
该设置独立持久化，同时淡出包裹层的背景模糊、染色、边线与柔光，不改变气泡按钮的透明度和触控行为；墨水屏实色包裹层也遵循此设置。
子泡错开展开，沿弧形轨迹缩放，带轻微果冻回弹；只有展开/回收的 650/350ms 内出现三枚低亮微光，静止和半隐藏态不循环闪烁。
墨水屏使用临界阻尼并关闭微光。阅读气泡组保留可缩放立体玻璃图标；设置页沿用原有表面，关闭全局模糊时仍保持半透明；只有墨水屏使用实色。
漫画翻译页的“显示译文”开关关闭时显示原图；“翻译设置”打开“本地翻译（SMaLL-100）/AI 翻译”单选框，并显示当前选择。
翻译方式独立保存；旧配置或未知值默认 AI。两种方式都沿用全局翻译目标语言。
AI 方式沿用 AI 章节翻译预设中的模型、凭据和生成参数，不读取全局翻译设置中的提供商。
漫画翻译使用 `LegadoMangaTranslator.promptPrefix()` 在代码中独立定义的固定规则和 JSON 示例，
不采用章节翻译预设中的小说正文提示词。固定规则要求保留语义、角色语气和文字区域编号，禁止补写剧情；
简中、繁中和英文目标附带对应的 JSON 对话示例，其他语言仅使用固定规则。
只向服务发送 OCR 文字，不发送图片。JSON 示例属于运行时翻译提示词，会保留在生产代码中。
本地方式不读取 AI 预设或凭据，不发送翻译网络请求；原图来自在线书源时仍需网络读取原图。
切换方式会暂停队列，等待当前页安全结束后保存配置并重新验证已加载页缓存；不自动恢复翻译。
缓存签名包含翻译方式，SMaLL-100 模型摘要与分词/解码版本；不同方式不混用译图，也不会删除另一种方式的缓存。

## SMaLL-100 本地模型

采用 `R4kSo1997/small100-onnx-int8_v2` 固定提交 `d66e2265495ad8062e7289f7b484bebc7c4e9510` 的 INT8 ONNX 文件，
上游原模型为 MIT 许可的 `alirezamsh/small100`。清单在 `app/src/main/assets/models/small100-models.json`，
包含 encoder、merged decoder、`sentencepiece.bpe.model`、`vocab.json` 四个文件，合计 616,650,737 字节（约 588 MiB），不内置到 APK。
管理页按整套 SMaLL-100 展示下载、安装进度和删除；导入沿用多选官方兼容文件，可分次补齐，四个文件全部校验通过后才可用。
每个文件先流式写入临时文件，通过大小和 SHA-256 验证后原子替换；取消或失败保留已安装文件。
AI 方式的“补齐缺失”只处理基础图像模型；本地方式额外处理 SMaLL-100，也可直接点击 SMaLL-100 的下载按钮。
模型操作与推理共用维护流程与文件锁，不在模型缺失时隐式联网。

应用侧通过 SMaLL-100 专用裁剪版 ONNX Runtime Android 1.31.1 CPU 执行，SentencePiece 0.2.2 使用单独的 JNI 库，
不修改固定版本 Yakuyomi 子模块。SentencePiece 源码固定到 `e0cce7d37b065b5140349dbe12c6bcf6192fdd78`，
CMake 校验源码归档 SHA-256，首次原生构建需要下载依赖。Windows 构建不要求创建符号链接的权限。
原生依赖来源与许可：SentencePiece（https://github.com/google/sentencepiece，Apache-2.0）、
ONNX Runtime（https://github.com/microsoft/onnxruntime，MIT）。

定制运行库位于 `app/libs/onnxruntime-small100-1.31.1.aar`，构建来源、算子清单和重建步骤见
`tools/small100/README.md`。保留原始 ONNX 文件支持和文本翻译所需的量化、动态形状、控制流与融合算子，
裁剪未使用的内核、传统机器学习算子、内置生成算子、遥测组件和 RTTI。仅打包 arm64 CPU 运行库；
检测、OCR 和去字继续使用原有 Yakuyomi/NCNN，不依赖这些已裁掉的 ONNX 内核。
`verifySmall100Runtime` 在应用构建前检查 AAR 摘要和 native 文件集合。运行库版本参与本地译图缓存标识。
本次定制运行库为 9,908,168 字节，原完整版 arm64 运行库约 34.21 MB，运行库本体减少约 71%；
定制 JNI 为 82,448 字节。179 个 JNI 方法导出、所需 CPU API 符号以及两份 ELF 的 16 KiB 对齐检查通过。
这些是构建和静态兼容检查，尚不能证明裁剪库已经通过 arm64 实际模型推理。

编码器输入为目标语言 token + SentencePiece 词元 + EOS，解码从 EOS 开始，采用贪心解码和三层 KV cache，
最大序列长度 256，达到限制仍未出现 EOS 时明确报错。输入超过 1022 个词元时优先按标点拆分，
无合适标点时按 Unicode 码点拆分后重新分词，译文合回原 OCR 区域，不静默截断或改变区域顺序。
目标语言不支持时明确报错，不回退到 AI。推理仍限 arm64，与现有漫画图像处理的 ABI 限制一致。
空闲、暂停和模型维护时同时关闭图像处理 Pipeline、本地 ONNX sessions 和 SentencePiece handle。
漫画使用独立的编号与 JSON 输出提示词，不复用小说正文的提示词模板；网络重试沿用现有 AI 服务处理器。

漫画 AI 请求使用稳定的翻译规则前缀，要求先理解语义再自然表达，保留角色语气、情绪和人名，不补写剧情。
简中、繁中和英文目标各自附带一组固定 JSON 翻译示例；其他目标不附带示例，避免输出语言被带偏。
同页完全相同的 OCR 文字先去重，返回后按原区域顺序展开；仍严格校验编号唯一、齐全和译文非空。
单批最多 24 个去重区域，用户消息 JSON 字符预算取章节翻译预设输入上限与 4000 的较小值（至少 256）；
单个超长区域独立请求，保持文字区域完整。当前仍逐页处理，不跨页汇总或携带前页历史。
漫画请求的思考级别为 AUTO 时按 OFF 执行，显式选择的思考级别保留；OpenAI Chat 协议的 DeepSeek 官方端点
显式发送 thinking 开关，不向任意兼容中转添加该扩展。

已校验的批次译文先持久化到当前漫画版本目录的 `texts/`，后续网络失败、排版失败或进程重启后可复用成功批次。
缓存包含页面身份、完整有序 OCR 上下文、提示词版本、语言、模型和生成参数；不跨页复用孤立短句。
凭据和自定义请求头不写入缓存。损坏缓存按未命中处理；旧版本任务不能在清理后重新创建文字缓存。
新的提示词版本参与译图键，避免直接显示旧规则生成的译图。清除漫画或全部翻译缓存时，文字缓存随版本目录一起回收。
服务商提示词缓存仍由服务商决定；本地命中会减少 API 请求，不能据此推断服务商后台命中率或实际费用。

## 依赖与构建

本地交付使用 `:app:assembleAppRelease -PcoexistRelease=true -PenableAbiSplits=true`：Release 启用 R8 代码压缩与资源收缩，
分别生成 arm64-v8a 和 armeabi-v7a APK，不额外生成 universal 包。漫画原生翻译仍仅支持 arm64。
未配置正式签名时，Release 输出需签名后安装；本地测试包使用本机已有测试密钥，不能替换其他密钥签名的正式应用。

本地共存安装包使用 `:app:assembleAppRelease -PcoexistRelease=true -PenableAbiSplits=true`，
本机跨盘 KSP 缓存环境额外传入 `-Pksp.incremental=false`。
该开关保留 Release 的 R8 与资源收缩，使用本机已有 debug 签名和已注册的本地 Firebase 包名
`io.legato.kazusa.debug`，应用名称为“阅读·本地”，版本名增加 `-local`。
它可与 GitHub Release 的 `io.legato.kazusa` 同时安装，数据目录和 Provider authority 独立；
与同包名、同签名的本地 Debug 包属于同一安装，可覆盖更新。默认不启用该开关。


引擎通过 `third_party/yakuyomi-engine` 子模块固定到
`883737078aecb92ed796efac571bf066e217b1ab`，只引入 `engine` 和 `inference-core`，不初始化夜读子模块。
克隆后运行 `git submodule update --init third_party/yakuyomi-engine`。
使用 JDK 21，配置 `ANDROID_HOME` 或根目录 `local.properties`；需要 NDK 28.2.13676358、CMake 3.22.1。
引擎源码不打本地补丁，原有 GPLv3 许可和模型来源说明保留在子模块的 LICENSE 和 docs/MODELS.md。
应用内置固定提交的 `models/manga-models.json`，管理 detector/ocr/inpainter 三类七个文件（约 247 MB）。
模型管理可单项下载、补齐缺失、多选导入官方兼容文件、删除和取消操作；缺失模型时只提示进入管理页，不隐式联网补齐。
文件大小和 SHA-256 验证通过后才原子替换，失败或取消保留已安装模型，逐项展示错误；清单与离线导入不依赖网络。
应用级 MangaModelRepository 持有操作与进度，离开设置页不丢失。模型维护先暂停派发、等待正在执行的原生页完成并释放引擎，
再通过与推理共用的模型文件锁安装或删除；维护期间拒绝恢复翻译，操作完成后保持暂停。

## 资源与失败语义

- 单实例仓库串行执行整章页面任务。当前页优先，新正式阅读章节优先于旧章剩余任务；仅预加载的相邻章节不入队。
- 每页完成立即发布和原子保存检查点；处理中页面在进程重启后恢复为待处理，失败不阻塞后续页，再次开启时重试。
- 暂停后停止派发下一页，正在处理的页面安全收尾并保存；同一批次复用模型和原生引擎，暂停或队列空闲后释放。
- 切到后台暂停，返回同一阅读器恢复自动状态；退出阅读器关闭自动模式，保留队列。重新进入后由用户开启继续。
- 在线页复用 BookHelp 的书源解密与文件租约；本地/SAF 页创建任务快照，避免压缩包读取器释放文件后访问失效。
- 图像限制为宽 4096、高 8192、1200 万像素，解码前校验，不缩小原图进行 OCR。
- 默认 boxfill 去字。原图独立保留，译图采用临时文件后 rename 发布。
- 译图键包含原图 SHA-256、引擎/模型版本、目标语言、模型配置、生成参数及固定排版方案版本。凭据不进入文件名、缓存或日志。
- 原译切换同步更换 Coil 内存键、文件 owner、预览请求与区域解码来源，页面身份不变。
- 翻译状态与图片加载状态分开。失败保留原图，编号错位、重复、缺项或空译文均不接受。
- 译图及无文字标记保存在 `filesDir/manga_translation/books/<漫画摘要>/generation-<版本>/`；
  `queue.json` 通过临时文件、fsync 和原子替换保存任务及当前漫画的原译选择；模型位于 `filesDir/manga_translation/models`。
- 原译选择应用到所有已加载页面；选择原图不影响队列继续生成译图。检查点中的译图在原图摘要与当前配置重新校验后展示。
- 旧 `pages/` 缓存首次有效命中时复制到漫画目录建立归属；当前漫画清理后禁止再次导入旧缓存，不删除归属不明的旧文件。
- 气泡清理需要确认，仅清除当前漫画：先增加缓存版本、清空任务和译图引用，切回原图，再等待预览和高清解码的统一租约释放后删除。
  旧任务发布和文件提交均检查版本，不会在清理后恢复有效结果；其他漫画、原图和模型保留。

设置页另外提供“清除全部翻译缓存”：遍历内存和持久化漫画记录，包括本进程未打开的漫画，
递增版本、清空任务、切回原图并禁用旧缓存重新导入；通过统一文件租约回收旧译图和旧 `pages/` 目录。
两种清理都保留原图和模型。
