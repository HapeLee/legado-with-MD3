# 漫画翻译

阅读设置“全局”页的第一项“漫画翻译”默认关闭；开启后出现默认在左侧居中的“译”气泡。
气泡可拖动吸附左右边缘，吸附边和相对高度通过 MangaSettingsGateway 原子保存。
点击展开“自动翻译”“译文/原图”“清除”；再次点击主泡、空白或返回键收起。
阅读菜单、设置及弹窗显示时隐藏气泡。磨砂、高光和描边遵循当前主题；禁用模糊或墨水屏使用实色。
小窗口改用横排或紧凑排列。长按图片菜单只保留保存、分享、拷贝、设为封面等图片操作。
目标语言沿用翻译设置，模型与凭据沿用 AI 的章节翻译预设。只向服务发送 OCR 文字，不发送图片。
漫画使用独立的编号与 JSON 输出提示词，不复用小说正文的提示词模板；网络重试沿用现有 AI 服务处理器。

## 依赖与构建

引擎通过 `third_party/yakuyomi-engine` 子模块固定到
`883737078aecb92ed796efac571bf066e217b1ab`，只引入 `engine` 和 `inference-core`，不初始化夜读子模块。
克隆后运行 `git submodule update --init third_party/yakuyomi-engine`。
使用 JDK 21，配置 `ANDROID_HOME` 或根目录 `local.properties`；需要 NDK 28.2.13676358、CMake 3.22.1。
引擎源码不打本地补丁，原有 GPLv3 许可和模型来源说明保留在子模块的 LICENSE 和 docs/MODELS.md。
模型按固定提交的 models.json 下载并校验 SHA-256，仅下载 detector/ocr/inpainter 三类（约 247 MB）。

## 资源与失败语义

- 单实例仓库串行执行整章页面任务。当前页优先，新正式阅读章节优先于旧章剩余任务；仅预加载的相邻章节不入队。
- 每页完成立即发布和原子保存检查点；处理中页面在进程重启后恢复为待处理，失败不阻塞后续页，再次开启时重试。
- 暂停后停止派发下一页，正在处理的页面安全收尾并保存；同一批次复用模型和原生引擎，暂停或队列空闲后释放。
- 切到后台暂停，返回同一阅读器恢复自动状态；退出阅读器关闭自动模式，保留队列。重新进入后由用户开启继续。
- 在线页复用 BookHelp 的书源解密与文件租约；本地/SAF 页创建任务快照，避免压缩包读取器释放文件后访问失效。
- 图像限制为宽 4096、高 8192、1200 万像素，解码前校验，不缩小原图进行 OCR。
- 默认 boxfill 去字。原图独立保留，译图采用临时文件后 rename 发布。
- 译图键包含原图 SHA-256、引擎/模型版本、目标语言、模型配置、生成参数及固定排版方案版本。凭据不进入文件名、缓存或日志。
- 原译切换同步更换 Coil 内存键、文件 owner、预览请求与区域解码来源，页面身份不变。
- 翻译状态与图片加载状态分开。失败保留原图，编号错位、重复、缺项或空译文均不接受。
- 译图及无文字标记保存在 `filesDir/manga_translation/books/<漫画摘要>/generation-<版本>/`；
  `queue.json` 通过临时文件、fsync 和原子替换保存任务及当前漫画的原译选择；模型位于 `filesDir/manga_translation/models`。
- 原译选择应用到所有已加载页面；选择原图不影响队列继续生成译图。检查点中的译图在原图摘要与当前配置重新校验后展示。
- 旧 `pages/` 缓存首次有效命中时复制到漫画目录建立归属；当前漫画清理后禁止再次导入旧缓存，不删除归属不明的旧文件。
- 清理需要确认，仅清除当前漫画：先增加缓存版本、清空任务和译图引用，切回原图，再等待预览和高清解码的统一租约释放后删除。
  旧任务发布和文件提交均检查版本，不会在清理后恢复有效结果；其他漫画、原图和模型保留。

## 验证边界

不提供后台持续翻译服务或长图分段翻译。32 位应用明确拒绝翻译，继续正常阅读。
回归重点包括队列去重和优先级、失败、暂停、进程恢复、版本失效、文件租约、设置和气泡交互。
分页、条漫、双页、旋转、小窗口的真实设备体验，以及 arm64 原生推理、内存/温升和真实 AI 服务仍需真机验证。
